# Processus d'extraction de novels fantastique avec thématique culinaire

## Objectif
Identifier et documenter des novels (web novels, light novels) partageant le thème de la cuisine, idéalement en thème principal, soit en thème secondaire, dans un cadre fantastique ou épique similaire au Seigneur des Anneaux.

## Méthodologie

### 1. Recherche par mots-clés
Pour chaque site exploré, les recherches utilisent les termes suivants :
- `cooking fantasy novel`
- `culinary fantasy web novel`
- `food novel fantasy`
- `gourmet fantasy`
- `chef transmigration novel`
- `cooking system novel`
- `cuisine fantasy light novel`
- `foodie fantasy`

### 2. Critères de sélection
Un novel est conservé s'il répond à au moins un de ces critères :
- **Thème principal** : La cuisine est au cœur de l'intrigue (recettes, compétitions, gastronomie comme élément central de la progression).
- **Thème secondaire** : La cuisine apparaît régulièrement et contribue à l'intrigue (restauration, nourriture magique, recettes avec effets spéciaux).
- **Cadre fantastique** : Le roman se déroule dans un monde fantastique (fantasy, isekai, transmigration, système magique).

### 3. Format de fichier produit
Chaque novel identifié fait l'objet d'un fichier Markdown dans le dossier `inspirations/` avec la structure suivante :

```markdown
# [Titre du roman] - Source d'inspiration

## Résumé
[Synopsis du roman]

## Thématique culinaire
[Description de l'importance de la cuisine dans le roman]

## Éléments fantastiques
[Description des éléments de fantasy, transmigration, système, etc.]

## Pertinence pour le projet
[Analyse de la pertinence par rapport aux thèmes du Seigneur des Anneaux et au projet de jeu]

## Lien source
[URL du site où le roman est disponible]
```

### 5. Processus d'exploration
Pour chaque site :
1. Accéder à la page d'accueil ou à la page de recherche.
2. Rechercher avec les mots-clés définis.
3. Examiner les résultats et sélectionner les novels correspondant aux critères.
4. Lire le premier chapitre ou la description pour confirmer la pertinence.
5. Rédiger le fichier Markdown correspondant dans `inspirations/`.
6. Mettre à jour le fichier `inspirations/index.md` avec le récapitulatif.

### 6. Fichier index récapitulatif
Un fichier `inspirations/index.md` sera créé pour lister tous les novels trouvés avec :
- Titre
- Auteur (si disponible)
- Thème principal/secondaire
- Lien vers le fichier Markdown dédié
- Pertinence (Élevée / Moyenne / Faible)
