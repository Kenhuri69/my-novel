# Taxonomie — Items : armes, armures, potions, ustensiles, artefacts

> Catalogue des objets du roman, pensé pour le jeu (`resources/`) autant que pour l'écriture.
> Identifiants par catégorie (**ARM-, VET-, POT-, UST-, ART-, DOC-, DIV-xxx**).
> Champs : Rareté · Porteur · Effet / usage · Origine · Chapitre.
> Principe d'univers : **les armes servent à protéger la cuisinière pendant qu'elle cuisine** ;
> aucune arme ne gagne un conflit dans ce roman. Les ustensiles sont les vrais objets de pouvoir.

## 1. Axes de classification

### 1.1 Catégories
| Code | Catégorie | Ce que c'est ici |
|---|---|---|
| **ARM** | Armes | arcs, lames, bâtons : protéger, dissuader, faire hésiter |
| **VET** | Vêtements et protections | tabliers, capes, uniformes, masques : identité plus que défense |
| **POT** | Potions et fioles | le mana de la Guilde ; ce que les gens « mangent » |
| **UST** | Ustensiles de cuisine | marmites, louches, couteaux : les objets qui *servent* |
| **ART** | Artefacts | graines, luth, carte, sceptres : objets uniques à histoire |
| **DOC** | Documents et mémoire | carnets, registres, dossiers, décrets |
| **DIV** | Divers | conques, outres, bougies |

### 1.2 Rareté
| Rang | Nom | Exemple |
|---|---|---|
| ★ | Commun | fiole de mana, cuillère forgée par Gorm |
| ★★ | Artisanal | arc de Sylvie, tablier de lin |
| ★★★ | Héritage | trousseau de Brune, cuillère de Taïs, Marmite de Bronze |
| ★★★★ | Unique | graine de bronze, Luth de Série, Carte des Saveurs |

### 1.3 Ce qu'un objet fait dans ce monde
- Il **porte** une mémoire (tablier, cuillère, croûte).
- Il **canalise** (graine, luth, bâton de cristal).
- Il **sert** (marmite, louche, four).
- Il **désigne** (sceptre, médaille, masque, cape).
Aucun objet ne donne de « +2 ». Un objet change ce qu'un personnage *peut oser*.
